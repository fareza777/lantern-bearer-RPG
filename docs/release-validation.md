# Act III validation — 2026-09-29

The local v3.0.0 continuation includes Act III integration, 10 playable classes, level 60, 14 zones, the Ember Forge, 76 recipes, 16 runes, and seven total endings. Existing saves and artwork were preserved.

## Artwork

163 missing raster assets were generated and installed: 40 enemies, 55 equipment bases, 25 unique items, 12 consumables, five materials, ten quest items, and 16 runes. Visual review covered every group. Sunglass and Emberplate were regenerated to correct subject mismatches. Original generated sources and rejected first versions are retained; revision records are in `art-revisions.json`.

## Executed checks

- `node tools/verify-content.cjs --allow-missing-voice --manifest`: 25 scripts, 4,368 assertions; zero broken required assets.
- `node tools/test-gameplay.cjs --legacy --balance`: ten classes, 296 skill/rank cases, all 76 recipes, rune/reforge transactions, quest progression, combat regressions, and 12 saves generated by the committed legacy engine passed. Forty class/boss smoke simulations won using finite healing resources; this is not exhaustive balance certification.
- `node tools/test-browser.cjs`: actual interaction checks passed with zero page errors and zero missing assets; mobile layouts checked at 320, 360, 390, and 430 pixels.
- `node tools/build-cache.cjs` then `node tools/test-offline.cjs`: all 447 cached files read and all 393 raster images decoded after networking was disabled and the test server stopped. Repeated after the final Emberplate revision.
- Raster audit: no opaque sprites and no identical image files. Equipment review found no clipped canvas edges.
- `git diff --check`: passed; only Windows line-ending notices.

Browser checks used isolated test profiles and did not read or change the user's saves. Machine-readable results and screenshots are in `qa/`. Android build/signature/package verification is recorded separately in `android-build.md`; physical Android device testing has not been performed.

## Remaining external dependency

17 new narration clips could not be generated because the configured ElevenLabs API returned HTTP 401. Their exact scripts are ready in `tools/vo_lines.json`. Existing narration remains intact; new cinematics use timed subtitles with music and avoid requesting nonexistent clips. The content checker permits only this explicit optional-voice exception; it still requires all game artwork and existing audio.
